# FGI 질적연구 AI 코딩 분석

FGI(초점집단면접) 전사본을 붙여 넣으면 AI가 Braun & Clarke 주제분석 단계(개방 코딩 → 코드북 → 주제 묶기 → 원자료 검토 → 보고서 초안)를 차례로 도와주는 사내용 웹 화면입니다.

- 주소: https://scv.job.or.kr/fgi/ (사무실 네트워크·직원 VPN 에서만)
- 만든 사람: 최진명

## 쓰는 법
1. 화면 위 **"분석에 쓸 AI"** 에서 Claude 또는 Gemini 를 고릅니다. 단계마다 바꿔도 되고, 결과에는 단계별로 어느 AI가 분석했는지 표시됩니다.
2. 전사본을 붙여 넣거나 파일(txt·md·hwpx·docx·doc)을 올립니다. **참여자 이름은 P1, P2 처럼 꼭 익명화**해 주세요. 전사본은 고른 AI 회사로 전송됩니다.
   - 녹음만 있으면 **🎙️ 음성 파일 → 글** 을 눌러 파일을 끌어다 놓으세요. 이 서버 안에서 글로 바꿉니다(1시간 녹음에 15분쯤, 말한 사람 구분은 안 됨).
   - **🕶️ 개인정보 가리기** 에 참여자 이름을 한 줄에 하나씩 적으면 P1, P2…로 바꿔 줍니다. 전화·주소 등은 자동으로 찾아 줍니다. 자동 찾기는 놓치는 것이 있으니 표를 확인하고, 빠진 것은 칸에서 직접 고치세요.
3. 1단계부터 버튼을 눌러 진행하고, 마지막에 결과를 내려받습니다(.md 파일).

## 관리자용
API 키는 서버 설정 파일에 들어 있습니다. Gemini 키를 넣거나 바꿀 때:

```
ssh -t <계정>@192.168.0.97 "sudo bash /srv/projects/fgi-analyzer/deploy/setgemini.sh"
```

키는 화면에 보이지 않게 입력하며, 맞는 키인지 먼저 확인한 다음 저장하고 앱을 다시 시작합니다.
